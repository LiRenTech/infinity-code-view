# 需求与迭代顺序

核心目标：源码只读，允许选择、标注和批注；用户建立的空间记忆优先于自动整齐排列。

## 第一阶段：项目空间（已实现）

- [x] 本地项目选择，按嵌套 `.gitignore` 扫描。
- [x] DOM 二维画布，滚轮缩放、中键平移、空白框选和批量移动。
- [x] 目录嵌套矩形，弹性包围内容，空目录保留最小尺寸。
- [x] 文件/目录可拖动，目录带动子树；同层默认允许重叠。
- [x] 非代码紧凑卡片，代码高亮、只读选中、自动换行和可调宽度。
- [x] 初次读取使用真实 DOM 高度校准布局；之后仅主动整理指定目录。
- [x] 布局和视口独立持久化，支持明暗主题。
- [x] 一键重置旧布局与宽度，重新布局并保存，支持会话内撤销重置。
- [x] 按目录层级逐步披露，宏观视图卸载源码和隐藏子树，边框动态补偿，大标题完整居中。
- [x] 手动刷新时保留位置；新增找空位、删除不重排、内容变长只调整高度。

## 第二阶段：批注（已实现）

- [x] 文件、目录和选中代码片段的批注。
- [x] 独立批注块与指向目标的连线，默认在目标旁边生成。
- [x] 批注参与外层目录包围盒，可以拖动并持久化。
- [x] 批注存储在应用数据中，不在源码目录创建文件。

## 第三阶段：连线与锚点（已实现基础版本）

- [x] 支持两个文件/目录、跨文件片段、同一文件不同片段之间连线。
- [x] 连线文字、颜色、粗细和虚实样式。
- [x] 锚点分为对象锚点、代码片段锚点，数据结构保留版本和扩展字段。
- [x] 对象定位允许完整项目路径、任意层数路径后缀、单文件/目录名。
- [x] 选择路径级别时显示当前匹配数量，明确唯一和多个候选。
- [x] 代码定位由可选路径范围与原样选中文字组成；全局唯一代码可省略路径。
- [x] 所有匹配在忽略规则过滤后的项目中进行，避免构建产物制造重复匹配。
- [x] 唯一后缀在目录移动后仍可重定位；首期不做文件内容身份追踪。
- [x] 不静默选择多个匹配中的某一项。失效连线侧栏区分“多个匹配”“目标缺失”。
- [x] 切换分支后通过刷新重新解析；`extensions` 预留前后文等辅助信息，暂不参与匹配。
