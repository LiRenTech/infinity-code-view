# InfinityCodeView 架构

## 已实现范围

- Tauri 负责本地项目扫描；Rust `ignore` 处理多层 `.gitignore`、反向规则和 `.git/info/exclude`，包括未初始化 Git 的目录。不跟随符号链接，跳过 `.git`，保留普通隐藏文件和空目录。
- React DOM 负责代码全文展示、文本选中、高亮、自动换行；文件标题拖动，整个右侧边缘及右下角调整代码卡片宽度；新代码卡片默认 1024px 宽，容纳至少 120 个等宽字符。
- 世界坐标与视口分开；滚轮围绕鼠标缩放，中键平移，空白区域左键框选，Shift 追加选择。选中父子时只移动一次。
- 节点使用项目相对路径作为第一阶段身份，子节点使用父框内的相对坐标。文件夹由内容包围盒推导；包围盒收紧/扩张时补偿坐标，保持其他节点的世界位置。
- 初次使用按面积估算的分行布局，并在 DOM 渲染后使用真实卡片高度校准一次。刷新时沿用原有节点坐标，仅为新增节点找空位。内容增长允许重叠；整理操作只排布所选目录的直接子节点。
- “重置布局”丢弃旧坐标和卡片宽度，重新测量、全树排布并保存；提供当前项目会话内最近一次重置的撤销。
- `presentation.ts` 按节点投影尺寸与目录深度决定层级披露，父目录折叠时不挂载子树。未选中文件的代码投影字号小于 8px 时不挂载高亮源码 DOM。选中文件及其全部祖先构成独立的强制披露集合，渲染和框选使用相同的披露规则；不改变视口或节点布局，取消选择后恢复缩放规则。
- 外框始终采用模型中的尺寸，天然内容单独测量，缩放切换不会造成节点收缩。导入、刷新和重置时用一次性隐藏的纯文本测量层校准实际高度，避免宏观视图为了测量而高亮所有源码。
- 边框使用不影响坐标的内描边，随缩放补偿为约 1–3.2 个屏幕像素，极小矩形限制描边占比。大标题按真实字体测量缩放，短名称保持单行，长名称换行，完整居中。
- 框选只命中当前披露的节点，隐藏子节点不会被误选；双击概览标题自动展开祖先并定位。
- 布局和视口版本化保存到应用数据目录 `layouts/`，不写入被阅读的代码项目。手动保存并显示修改状态。

## 当前边界

- 手动刷新项目，暂未接入文件监视器。重命名/移动当前按删除+新增处理；后续应把路径身份与可重定位锚点分开。
- 所有可识别、UTF-8、至多 2 MiB 的代码/文本格式文件展示全文。二进制、未知类型、锁文件、过大或无法解码的文件以紧凑卡片展示，并在适用时标明原因。
- 已支持缩放分层和折叠子树剔除，尚未支持按视口范围剔除和后台高亮调度；较近视图下，超大项目仍可能有性能压力。
- 默认允许同层重叠，碰撞模式尚未实现。
- 批注和连线通过手动保存持久化；目前不做语义/模糊代码匹配，源码改写后可能需要手动修复。

## 批注、连线与锚点

- `relations.ts` 定义对象锚点、代码锚点、批注、连线和可扩展的 `version/extensions`。路径匹配区分完整路径和按路径段匹配的后缀；代码只搜索项目扫描结果中的可读代码，统一 CRLF/LF 后按原文搜索，统计所有出现次数（含同文件重复和重叠出现）。候选详情最多保留 20 个，但匹配数量保持准确。
- 解析结果只有 `resolved / ambiguous / missing`，仅两端均唯一时才绘制。失效侧栏保留原始锚点、支持编辑；刷新/切换分支后刷新会重新解析。不存在“默认选第一个候选”的降级策略。
- `annotation-layout.ts` 将独立批注挂为目标的同级虚拟节点（根目标挂在根目录内），使用不能出现在真实路径中的 NUL 前缀隔离身份。它们参与正常包围盒、拖动、宽度和测量逻辑，源码快照仍只包含磁盘文件。
- 批注目标失效时保留节点；原父目录不存在则回落到根目录。刷新、归属变化和版本恢复时用世界坐标换算相对位置，防止目录收紧造成批注漂移。新批注在目标旁边找空位；已有批注优先保留位置。
- 布局文档版本 2 在原几何/视口字段外新增 `relations`。批注世界坐标随保存更新，旧版 1 文档读取时迁移为空批注/连线，保存才升级。加载时验证数据，不静默抛弃损坏记录。重置、撤销重置和普通保存都携带完整关系数据。
- `ConnectionLayer` 在视口内用 SVG 屏幕坐标绘制，线宽不随缩放失控。源码的字符偏移通过 `dom-ranges.ts` 穿过高亮 span 建立 DOM Range，使用真实换行后的文本范围；同文件两端从右侧绕行。折叠时指向最近的可见祖先，不能把展示折叠误报为锚点失效。
- 点击连线选中侧栏记录；定位代码会展开文件并移动到片段，而“查看两端”根据两端包围盒调整视口。所选连线高亮实际代码范围。
- `AnnotationLayer` 以世界坐标统一渲染可见批注，放在文件树和 SVG 连线上方，避免嵌套目录的 stacking context 遮挡批注；逻辑父节点和目录包围盒规则保持不变。折叠目录的隐藏批注仍不挂载。
- 批注没有标题栏，非编辑时整块可拖动，双击切换原地 textarea 并保留原生选字；文本实时写入关系状态，失焦或 Cmd/Ctrl+Enter 结束、Esc 恢复进入编辑时的内容，保存布局时统一持久化。隐藏镜像与编辑器共享排版，让测量随内容自然增长。锚点和连线样式仍在模态窗口编辑；画布源码始终只读。删除关系的撤销使用当前场景重新挂接批注，不回滚删除后无关的文件移动。
