# InfinityCodeView 第一阶段

## 已实现范围

- Tauri 负责本地项目扫描；Rust `ignore` 处理多层 `.gitignore`、反向规则和 `.git/info/exclude`，包括未初始化 Git 的目录。不跟随符号链接，跳过 `.git`，保留普通隐藏文件和空目录。
- React DOM 负责代码全文展示、文本选中、高亮、自动换行；文件标题拖动，整个右侧边缘及右下角调整代码卡片宽度；新代码卡片默认 1024px 宽，容纳至少 120 个等宽字符。
- 世界坐标与视口分开；滚轮围绕鼠标缩放，中键平移，空白区域左键框选，Shift 追加选择。选中父子时只移动一次。
- 节点使用项目相对路径作为第一阶段身份，子节点使用父框内的相对坐标。文件夹由内容包围盒推导；包围盒收紧/扩张时补偿坐标，保持其他节点的世界位置。
- 初次使用按面积估算的分行布局，并在 DOM 渲染后使用真实卡片高度校准一次。刷新时沿用原有节点坐标，仅为新增节点找空位。内容增长允许重叠；整理操作只排布所选目录的直接子节点。
- “重置布局”丢弃旧坐标和卡片宽度，重新测量、全树排布并保存；提供当前项目会话内最近一次重置的撤销。
- `presentation.ts` 按节点投影尺寸与目录深度决定层级披露，父目录折叠时不挂载子树。未选中文件的代码投影字号小于 8px 时不挂载高亮源码 DOM。选中文件及其全部祖先构成独立的强制披露集合，渲染和框选使用相同的披露规则；不改变视口或节点布局，取消选择后恢复缩放规则。
- 外框始终采用模型中的尺寸，天然内容单独测量，缩放切换不会造成节点收缩。导入、刷新和重置时用一次性隐藏的纯文本测量层校准实际高度，避免宏观视图为了测量而高亮所有源码。
- 边框使用不影响坐标的内描边，随缩放补偿为约 1–3.2 个屏幕像素，极小矩形限制描边占比。大标题按真实字体测量缩放，短名称保持单行，长名称换行，完整居中。
- 框选只命中当前披露的节点，隐藏子节点不会被误选；双击概览标题自动展开祖先并定位。
- 布局和视口版本化保存到应用数据目录 `layouts/`，不写入被阅读的代码项目。手动保存并显示修改状态。

## 当前边界

- 手动刷新项目，暂未接入文件监视器。重命名/移动当前按删除+新增处理；后续应把路径身份与可重定位锚点分开。
- 所有可识别、UTF-8、至多 2 MiB 的代码/文本格式文件展示全文。二进制、未知类型、锁文件、过大或无法解码的文件以紧凑卡片展示，并在适用时标明原因。
- 已支持缩放分层和折叠子树剔除，尚未支持按视口范围剔除和后台高亮调度；较近视图下，超大项目仍可能有性能压力。
- 默认允许同层重叠，碰撞模式尚未实现。
- 批注、标注和连线尚未实现。

## 下一阶段

1. 增加批注实体：独立存储，显示在目标同级目录中，参与包围盒计算。
2. 增加可扩展的锚点结构：`kind`、路径后缀、选中文字以及预留上下文扩展字段。匹配结果必须为“唯一/多义/缺失”，绝不静默选择多个候选中的一个。
3. SVG 连线层连接 DOM 代码范围和文件框；实现连线样式、文字以及失效连线侧栏。
4. 文件监视器增量同步、布局撤销/重做、碰撞开关与大项目渲染优化。
