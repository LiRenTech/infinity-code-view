# InfinityCodeView

在二维无限画布中阅读项目，用自己摆放的文件位置建立空间记忆。基于 Tauri 2、React、TypeScript 和 DOM。

目前已支持项目空间、只读代码浏览、批注与可重定位连线。

## 运行

需要 Node.js、pnpm、Rust 及系统的 [Tauri 开发环境](https://v2.tauri.app/start/prerequisites/)。

```sh
pnpm install
pnpm tauri dev
```

`pnpm dev` 仅运行浏览器界面，可点击“体验示例”验证画布交互。本地目录选择和项目读取需要 Tauri 桌面应用。

## 使用

- 点击“打开项目”，选择目录。扫描遵循嵌套 `.gitignore`，不展示 `.git`，不跟随符号链接。
- 滚轮围绕鼠标缩放；中键拖动视野；`F` 适应全图。缩小时按目录层级折叠为大标题；单击文件夹展开当前层（含直接文件的代码），双击递归展开全部后代与代码，视野位置和缩放保持不变。文件大标题仍可双击定位。
- 选中的文件在任何缩放下都显示完整内容，所有祖先目录保持展开、取消覆盖式大标题；点击、Shift 点选、框选均生效。
- 文件夹的展开效果只由点击触发；框选或拖动文件夹不会触发展开。取消选中后恢复正常概览。
- 顶栏“设置”中可分别关闭“单击文件夹展开当前层”“双击文件夹递归展开”“选中文件时显示完整代码”。三项默认开启，自动保存、对所有项目生效，也可一键恢复默认。
- 宏观视图卸载未选中文件的代码和折叠目录的内部节点，放大到文字可读时才显示源码；边框随缩放补偿粗细。标题自动缩放、必要时换行，完整居中且不超出框。
- 拖动文件或文件夹标题改变位置。文件夹随内容伸缩，拖动文件夹会带动全部子项。
- 空白处左键拖动框选；`Shift` 点击标题追加/取消选择，再拖动任意选中标题批量移动。
- 代码可以选中、复制，不能编辑；拖动右侧边缘（含右下角）改变卡片宽度，代码自动换行。新代码卡片默认宽 1024px，至少容纳 120 个等宽字符；已保存的自定义宽度继续保留。
- 左侧查找文件并点击定位。右上角切换明暗主题，暗色配色参考 [VS Code Dark Modern](https://github.com/microsoft/vscode/blob/main/extensions/theme-defaults/themes/dark_modern.json)。
- 文件卡片按后缀和特殊文件名配色（CSS 粉、JS 黄、TS 蓝），常见目录名也有配色；大标题使用淡填充、彩色文字与边框，展开后保留源码语法高亮。文件与目录关联参考 [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme)，并为明暗主题调整了文字对比度。
- 选择单个文件夹，点击“整理这个文件夹”仅排列其直接子项。
- “重置布局”清除整个项目的旧位置与宽度，使用当前默认宽度重新排布并自动保存。本次打开项目期间可用“撤销重置”恢复最近一次重置前的布局与视口。
- “刷新”重新读取磁盘，保留已有节点位置。新增文件寻找空位；删除和代码增长不触发整体重排。
- 点击“保存布局”或 `Cmd/Ctrl+S` 保存布局与视口。切换项目时先保存当前布局。

## 批注与连线

- 选中文件或文件夹，点击画布工具栏“添加批注”；选中一段代码后，按钮变为“批注选中代码”。批注块默认出现在目标旁边，参与外层目录边框，支持拖动、批量移动和调整宽度。
- 批注只显示内容，双击即可原地编辑。非编辑时整块拖动，编辑时拖动选择文字；点击外部或 `Cmd/Ctrl+Enter` 结束编辑，`Esc` 取消本次编辑。批注始终显示在文件、文件夹与连线上方。
- 连线可以先“设为连线起点”，再选择另一个文件、文件夹或代码片段，点击“连接到当前目标”。也可 Shift 选中两个对象后“连接所选两项”。支持跨文件和同一文件不同代码位置。
- 编辑窗口里可选择完整路径、不同级别的路径后缀；代码锚点还可选“全项目代码”。路径选项显示匹配文件/目录数，下面显示实际代码位置的匹配数。也可直接修改路径和代码匹配条件来修复锚点；这些操作不修改源码。
- 连线支持文字、颜色、粗细、实线/虚线。点击连线可在“批注与连线”侧栏选中，再编辑样式和端点。代码精确位置通过 DOM Range 获取，调整宽度与换行后会重新定位。
- 侧栏支持定位起点、终点、批注或同时“查看两端”。所选连线会高亮目标代码。内容折叠时，连线暂时指向可见的外层框。
- 项目刷新后重新匹配锚点。无法唯一匹配的连线保留在“失效连线”中，区分“多个匹配”“目标缺失”；修复后自动恢复绘制，不会自动从多个候选中挑选一个。
- 目标缺失时，批注本身仍保留；原目录也被删除时，暂放到项目根框，保持世界坐标。目标恢复后重新归属对应目录。
- 编辑窗口支持删除批注或连线，工具栏可撤销最近一次删除。重置布局与撤销重置均保留批注和连线数据。
- 点击“保存布局”或 `Cmd/Ctrl+S` 将布局、批注和连线一起保存。旧版布局自动兼容读取，保存后升级到版本 2。

布局保存到 Tauri 应用数据目录的 `layouts/` 子目录，不修改被阅读项目。macOS 路径为 `~/Library/Application Support/com.fittencode.infinity-code-view/layouts/`。示例布局保存到 WebView 的 localStorage。

```sh
cargo test --lib

```

## 当前边界与后续

当前以手动刷新同步变化，同层节点允许重叠。代码文件按支持的扩展名识别，UTF-8 且不超过 2 MiB 时展示全文；其他文件使用紧凑卡片。大项目的视口范围剔除与高亮调度、碰撞模式、布局撤销、自动监视尚未实现。

代码锚点目前使用原样代码匹配（统一换行符），尚未加入上下文模糊匹配；路径后缀重定位不验证内容身份。数据结构预留扩展字段，详见 [架构说明](docs/architecture.md)。
